
# Zepto Inventory Data Analysis using MySQL

## Project Overview
This project analyzes a real-world Zepto inventory dataset using MySQL. It covers data cleaning, exploratory data analysis (EDA), and business-driven SQL queries to generate meaningful insights.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Project Workflow
- Database Creation
- Data Import
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Business Problem Solving

## Data Cleaning
- Checked for NULL values
- Checked duplicate records
- Removed invalid price records
- Converted prices from paise to rupees
- Validated data consistency

## Business Questions Solved
- Top discounted products
- Category-wise revenue analysis
- High-value products with low discounts
- Best value-for-money products
- Product segmentation by weight
- Average discount by category
- Inventory analysis

## SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- HAVING
- ORDER BY
- LIMIT
- Aggregate Functions
- CASE
- UPDATE
- DELETE

## Outcome
This project demonstrates practical SQL skills for data cleaning, analysis, and solving real-world business problems using MySQL.
